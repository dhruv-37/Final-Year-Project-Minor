Explainable accounting-fraud detection (extension of Bao et al., JAR 2020)
==========================================================================
Contents
  README.md                     full write-up: what changed vs the paper, results, limitations
  presentation/                 Fraud_Detection_Project.pptx (+ .pdf copy): 24 slides with speaker notes
  run_pipeline.py, src/         the pipeline (features, models, evaluation, SHAP)
  score_new_data.py, scripts/   scorer for new firms + 20-firm smoke test
  data/                         data_FraudDetection_JAR2020.csv (public, from github.com/JarFraud/FraudDetection)
  results/                      every number in the README and slides, plus the saved model (final_models.joblib)
  improvements.bundle           the 4 git commits of the improvement work (git fetch improvements.bundle improvements:improvements)

Reproduce everything (about 18 min on a laptop CPU):
  python -m venv venv && venv\Scripts\activate          (Windows)
  pip install -r requirements.txt
  python run_pipeline.py                                  # full run, test years 2003-2014
  python run_pipeline.py --fast                           # 2003-2008 only, ~12 min
  python scripts/smoke_score.py                           # checks the scorer end to end
  python score_new_data.py --input firms.csv --year 2012 --out scored.csv

Notes
  - requirements.txt pins the exact library versions the saved model was built with.
  - Slide numbers for the paper's own results are approximate recollections of its Table 3;
    verify them against the paper before presenting (speaker notes say the same).
